Opwarmen

Wat is de output? 🤔

Stel dat de gebruiker Tim intypt.

string name = Console.ReadLine();
Console.Write("Dag");
Console.Write(name);
Console.WriteLine("!");
Console.WriteLine("Dag " + "name");
  • regel 2 tot 4 → DagTim!, want er staat geen spatie na “Dag”
  • regel 5 → Dag name, want "name" staat tussen aanhalingstekens

DagTim. Klinkt als een nieuw sociaal netwerk.

De syntaxis van C#

De regels van de taal

Een programma bestaat uit statements: instructies. De regels waaraan die moeten voldoen, heten de syntaxis.

  • Puntkomma: elk statement eindigt met ;, behalve een blok.
  • Blok: begint met {, eindigt met }, en bevat andere statements.
  • Hoofdlettergevoelig: Console en console zijn voor C# totaal verschillend.
  • Witruimte: spaties, tabs en enters negeert C#, behalve binnen aanhalingstekens.

Voor C# zijn Tim en tim twee verschillende personen. Hopelijk zijn ze niet getrouwd.

Witruimte 🤔

Compileren deze twee stukken code allebei?

Console.WriteLine("Hallo");
Console.WriteLine("wereld");
Console.WriteLine(
      "Hallo"
   );   Console.WriteLine("wereld");

✅ Ja, allebei. Ze doen ook exact hetzelfde.

Maar de rechtse kost je op een evaluatie een punt voor de bladspiegel. Laat Visual Studio je code netjes zetten met Ctrl + K, Ctrl + D.

Code die werkt maar er slordig uitziet, is als een taart die smaakt maar op de grond gevallen is.

Sleutelwoorden

C# heeft ongeveer 80 sleutelwoorden: woorden met een vaste betekenis, die je niet als naam mag gebruiken.

Dit semester leer je onder andere:

bool byte char double int long string if else switch case while do for return void namespace true false

In het tweede semester volgen onder andere class, public, private, new en static.

Tachtig gereserveerde woorden. Meer dan de meeste restaurants op vrijdagavond.

Commentaar

Uitleg in je code, die de compiler negeert:

// De start van het programma
int number = 3;
int result = number * 5;  // 15
/*
    Commentaar over
    meerdere regels
*/
Console.WriteLine(result);
  • //: de rest van de regel is commentaar
  • /* ... */: alles ertussen is commentaar, ook over meerdere regels
  • Handig om tijdelijk code uit te schakelen: Ctrl + K, Ctrl + C (en Ctrl + K, Ctrl + U om terug aan te zetten)

Goed commentaar legt uit waarom. Slecht commentaar: // tel 1 op. Ja, dat zagen we.

Datatypes

Wat voor gegevens?

Een datatype zegt wat voor soort gegevens je bewaart. Dat bepaalt ook hoeveel geheugen het inneemt.

Soort Datatypes
gehele getallen sbyte, byte, short, ushort, int, uint, long
kommagetallen float, double, decimal
tekst char (één teken), string (tekst)
waar of niet waar bool

Een datatype is als een doos: je stopt geen soep in een schoenendoos.

Gehele getallen

Type Geheugen Bereik
sbyte 8 bits -128 tot 127
byte 8 bits 0 tot 255
short 16 bits -32 768 tot 32 767
ushort 16 bits 0 tot 65 535
int 32 bits ongeveer -2,1 miljard tot 2,1 miljard
uint 32 bits 0 tot ongeveer 4,3 miljard
long 64 bits ongeveer -9,2 tot 9,2 triljoen
  • De s van sbyte staat voor signed: met een plus- of minteken.
  • De u van ushort, uint en ulong staat voor unsigned: altijd positief.

sbyte gaat tot 127. Genoeg voor je leeftijd, niet voor je aantal ongelezen mails.

Past het? 🤔

Code Compileert?
byte age = 300; ❌ een byte gaat maar tot 255 (CS0031)
sbyte temperature = -20; ✅
ushort year = 2026; ✅
int population = 11800000; ✅ 11,8 miljoen past ruim
int worldPopulation = 8100000000; ❌ te groot, gebruik een long (CS0266)

8,1 miljard mensen passen niet in een int. Ook niet als ze inschuiven.

Kommagetallen

Type Geheugen Voordeel
float 32 bits neemt het minste geheugen in
double 64 bits het grootste bereik: heel grote en heel kleine getallen
decimal 128 bits de grootste precisie: 28 tot 29 cijfers

Tip

Bij twijfel: int voor gehele getallen, double voor kommagetallen.

decimal rekent tot 29 cijfers precies. Je bank gebruikt het. Hopelijk.

Tekst en booleans

  • string: tekst, tussen dubbele aanhalingstekens: "Hallo wereld!"
  • char: precies één teken, tussen enkele aanhalingstekens: 'à'
  • bool: enkel true of false, waar of niet waar

bool lijkt nu nog nutteloos, maar in H4 (beslissingen) gebruik je het overal.

Een bool kent maar twee antwoorden. Ideaal voor discussies met tieners.

Welk datatype? 🤔

Gegeven Datatype
je leeftijd int (of byte)
de prijs van een frietje double (of decimal)
je voornaam string
ben je geslaagd? bool
de eerste letter van je naam char
het aantal mensen op aarde long

De prijs van een frietje als int? Dan rondt de frituur altijd af naar boven.
