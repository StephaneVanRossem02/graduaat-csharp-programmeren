Logische operatoren

EN, OF en NIET

C#-syntax Betekenis Wanneer true?
&& en-operator als beide kanten true zijn
\|\| of-operator als minstens één kant true is
! niet-operator draait het resultaat om

Je zet && en || tussen twee booleaanse expressies, en ! ervoor.

Wie technologie of elektronica gehad heeft: ja, dat zijn jullie AND-, OR- en NOT-poorten. Zonder soldeerbout deze keer.

&&: allebei

Je mag de rollercoaster op als je minstens 1,40 m bent en minstens 12 jaar.

int height = 145;
int age = 11;
bool mayRide = height >= 140 && age >= 12;
Console.WriteLine(mayRide);  // False

Groot genoeg, maar te jong: één kant is false, dus het geheel is false.

Allebei waar, of je blijft aan de kant met de suikerspin.

||: minstens één

Je krijgt korting op het openbaar vervoer als je jonger dan 18 of ouder dan 65 bent.

int age = 70;
if (age < 18 || age > 65)
{
    Console.WriteLine("Korting op het openbaar vervoer!");
}

70 < 18 is false, maar 70 > 65 is true. Eén van de twee volstaat.

||: de enige operator die tevreden is met de helft.

!: omdraaien

Console.WriteLine(!(0 == 2));  // True

bool isRaining = false;
if (!isRaining)
{
    Console.WriteLine("Laat de paraplu maar thuis.");
}

Lees ! hardop als “niet”: “als het niet regent”.

!true is false. Net als “ik heb alle oefeningen van vorige week gemaakt”.

Waarheidstabellen

&& (EN)

&& false true
false false false
true false true

|| (OF)

\|\| false true
false false true
true true true
  • && is enkel true als alles true is.
  • || is enkel false als alles false is.

Waarheidstabellen: de enige tabellen waarin nooit gelogen wordt.

Test jezelf 🤔

Is het resultaat true of false?

  1. 3 > 2 → true
  2. 4 != 4 → false
  3. 4 < 5 && 4 < 3 → false
  4. "a" == "a" || 4 >= 3 → true
  5. (3 == 3 && 2 < 1) || 5 != 4 → true
  6. !(4 <= 3) → true
  7. true || false → true
  8. !true && false → false

Acht vragen, telkens true of false. Gokken geeft gemiddeld 50%. Net niet geslaagd.

Vereenvoudigen

Zonder ||

Twee ruiten, en twee keer dezelfde output.

Twee keer dezelfde tekst typen? Copy-paste is geen programmeerstijl.

Zonder || in C#

if (age < 18)
{
    Console.WriteLine("Korting op het openbaar vervoer!");
}
else if (age > 65)
{
    Console.WriteLine("Korting op het openbaar vervoer!");
}
else
{
    Console.WriteLine("Geen korting!");
}

Met ||

if (age < 18 || age > 65)
{
    Console.WriteLine("Korting op het openbaar vervoer!");
}
else
{
    Console.WriteLine("Geen korting!");
}

Ook met strings

Console.WriteLine("Welke dag is het?");
string day = Console.ReadLine();
if (day == "zaterdag" || day == "zondag")
{
    Console.WriteLine("Weekend!");
}

Waarschuwing

Elke kant van || moet een volledige vergelijking zijn. day == "zaterdag" || "zondag" compileert niet.

Weekend detecteren met ||. Het nuttigste programma van het jaar.

Valkuilen

Intervallen

Is iemand tussen 12 en 18 jaar (grenzen inbegrepen)?

bool isTeenager = 12 <= age <= 18;     // ❌ CS0019
bool isTeenager = age >= 12 && <= 18;  // ❌ CS1525
bool isTeenager = age >= 12 && age <= 18;  // ✅

Twee volledige vergelijkingen, verbonden met &&.

12 <= age <= 18 werkt in de wiskunde. C# heeft nooit wiskunde gevolgd.

&& gaat voor ||

Console.WriteLine(true || false && false);    // True
Console.WriteLine((true || false) && false);  // False

Net zoals * voor + gaat, wordt && eerst berekend.

Tip

Twijfel je? Zet haakjes. Ze maken je bedoeling duidelijk, voor de compiler en voor de lezer.

Haakjes kosten niets. Je collega’s bedanken je ermee.

Scope

Wat is scope?

De plaats waar je een variabele declareert, bepaalt waar je ze mag gebruiken.

Vuistregel: een variabele bestaat vanaf haar declaratie tot de sluitende accolade } van het blok waarin ze staat.

if, en straks ook loops en methoden, maken telkens een nieuw blok met accolades.

Wat in de accolades gebeurt, blijft in de accolades. Zoals Las Vegas, maar met meer puntkomma’s.

Te laat gebruikt

if (age >= 18)
{
    string message = "Welkom!";
}
Console.WriteLine(message);  // ❌ CS0103

Waarschuwing

The name ‘message’ does not exist in the current context

message bestaat enkel binnen de accolades van de if.

message is met zijn accolade mee naar huis.

Oplossing: vroeger declareren

string message = "Te jong.";
if (age >= 18)
{
    message = "Welkom!";
}
Console.WriteLine(message);  // ✅

Declareer de variabele vóór de if. Binnen de if geef je ze enkel een nieuwe waarde.

Tip

Geef ze meteen een beginwaarde. Zonder beginwaarde krijg je fout CS0165: C# kan niet garanderen dat de variabele altijd een waarde heeft.

Een variabele zonder waarde is als een lege brooddoos: C# weigert die mee te nemen.

Dezelfde naam

int number = 0;
if (number == 0)
{
    int number = 5;  // ❌ CS0136
}

Zolang number in scope is, mag je geen tweede number maken.

Dit mag wel, want de eerste scope is al afgesloten:

{
    int number = 0;
}
{
    int number = 5;  // ✅
}

Twee variabelen met dezelfde naam in dezelfde scope? Zelfs C# raakt dan de tel kwijt.
