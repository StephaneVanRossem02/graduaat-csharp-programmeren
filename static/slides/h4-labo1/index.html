Waarom beslissingen?

Tot nu toe: lineair

Onze programma’s liepen braaf regel per regel van boven naar onder. Zoals een algoritme om brood te kopen:

  1. Neem geld uit spaarpot
  2. Wandel naar de bakker om de hoek
  3. Vraag om een brood
  4. Krijg het brood
  5. Betaal het geld aan de bakker
  6. Keer huiswaarts
  7. Smullen maar

Stap 7: het enige deel van het algoritme dat nooit faalt.

Programma’s die kiezen

Een beter algoritme reageert op de omstandigheden: is de bakker gesloten? Is er genoeg geld?

Het programma neemt beslissingen op basis van aanwezige informatie.

Voorbeelden in een bestelsysteem:

  • reageren als de voorraad van een product op is
  • korting geven op bepaalde dagen van de week
  • spaarpunten laten inwisselen

Een programma zonder beslissingen is als een gps die altijd “rechtdoor” zegt.

Booleaanse expressies

Relationele operatoren

Een booleaanse expressie is een stukje code dat true of false oplevert.

C#-syntax Betekenis
> groter dan
< kleiner dan
== gelijk aan
!= niet gelijk aan
<= kleiner dan of gelijk aan
>= groter dan of gelijk aan

Relationele operatoren: geen datingapp, wel vergelijkingen.

= of ==?

int age = 18;                  // toekenning: age wordt 18
Console.WriteLine(age == 18);  // vraag: is age gelijk aan 18?

Waarschuwing

“Gelijk aan” schrijf je met twee symbolen, omdat één = al gebruikt wordt voor een toekenning.

Eén = geeft een bevel, twee == stellen een vraag. Drie === is JavaScript, en daar praten we hier niet over.

Uittesten

Console.WriteLine(4 < 7);   // True
Console.WriteLine(4 < 2);   // False
Console.WriteLine(5 == 5);  // True
Console.WriteLine(5 != 5);  // False

Het resultaat kan je ook bewaren in een variabele van het type bool:

int age = 17;
bool isAdult = age >= 18;
Console.WriteLine(isAdult);  // False

C# schrijft True met een hoofdletter. Het is nu eenmaal zeker van zijn stuk.

Even testen 🤔

int number = 10;

Welke expressies leveren true op?

  1. number > 10 → ❌ false
  2. number >= 10 → ✅ true
  3. number != 3 → ✅ true
  4. number < 5 → ❌ false
  5. "C#" == "c#" → ❌ false

4 < 7 is true. Net als “maandag komt altijd te vroeg”.

Appelen met peren

De types die je vergelijkt, moeten vergelijkbaar zijn:

if ("4" > 3)   // ❌ compileert niet: string met int vergelijken

Zet eerst om, dan vergelijk je getallen met getallen:

if (Convert.ToInt32("4") > 3)   // ✅

De compiler vergelijkt geen appelen met peren. Hij is geen fruitboer.

if

Het idee

Een if bevat code die enkel uitvoert als een booleaanse expressie true oplevert. Dat heet conditionele code.

Van schema naar C#

string password = Console.ReadLine();
if (password == "gEhEiM")
{
    Console.WriteLine("Geheime informatie: ...");
    Console.WriteLine("Fijne dag nog!");
}
  • De ruit = de voorwaarde tussen de ronde haakjes na if
  • De tak True = de code tussen de accolades
  • De tak False = gewoon verder na de }

Een flowchart is een stripverhaal voor programmeurs. Alleen met meer ruiten en minder superhelden.

Met invoer van de gebruiker

Console.WriteLine("Hoe oud ben je?");
int age = Convert.ToInt32(Console.ReadLine());
if (age >= 18)
{
    Console.WriteLine("Je mag stemmen.");
}
Console.WriteLine("Bedankt!");
Hoe oud ben je?
16
Bedankt!

In België is stemmen voor de meeste verkiezingen zelfs een plicht. Ook dat is een if.

Accolades vergeten

if (password == "gEhEiM")
    Console.WriteLine("Geheime informatie: ...");
    Console.WriteLine("Fijne dag nog!");

Zonder accolades hoort enkel de eerste regel bij de if. De tweede regel wordt altijd uitgevoerd, ook met een fout wachtwoord. Het inspringen verandert daar niets aan.

Belangrijk

Voor ons is het simpel: we schrijven if altijd met accolades.

Accolades vergeten is als je broek vergeten: technisch kan je vertrekken, maar het loopt slecht af.

if/else

Een plan B

Vaak wil je iets anders doen als niet aan de voorwaarde voldaan is.

if/else: het enige moment waarop een computer een plan B heeft.

if/else in C#

if (password == "gEhEiM")
{
    Console.WriteLine("Geheime informatie: ...");
}
else
{
    Console.WriteLine("Maak dat je wegkomt!");
}
  • De tak True = het eerste blok accolades
  • De tak False = het blok na else
  • Er wordt altijd precies één van de twee uitgevoerd

Code voor beide gevallen

Wat je altijd wil doen, hoort niet in een vertakking. Zet het na de volledige if/else:

if (password == "gEhEiM")
{
    Console.WriteLine("Geheime informatie: ...");
}
else
{
    Console.WriteLine("Maak dat je wegkomt!");
}
Console.WriteLine("Fijne dag nog!");

“Fijne dag nog!” krijg je altijd. Zelfs als je net betrapt bent.

Nesting en else if

Nesting: een if in een if

if (password == "gEhEiM")
{
    Console.WriteLine("Geheime informatie: ...");
}
else
{
    Console.WriteLine("Dat klopt niet! Je krijgt nog één kans...");
    password = Console.ReadLine();
    if (password == "gEhEiM")
    {
        Console.WriteLine("Geheime informatie: ...");
    }
    else
    {
        Console.WriteLine("Ook niet juist.");
    }
}

Te diep nesten is als matroesjka’s openen: leuk, tot je de kleinste zoekt.

Meerdere gevallen

Niet het juiste wachtwoord, maar bijna? Dan geven we een hint.

Genest in C#

if (password == "gEhEiM")
{
    Console.WriteLine("Geheime informatie: ...");
}
else
{
    if (password == "geheim")
    {
        Console.WriteLine("Warm!");
    }
    else
    {
        Console.WriteLine("Koud!");
    }
}

Hetzelfde met else if

if (password == "gEhEiM")
{
    Console.WriteLine("Geheime informatie: ...");
}
else if (password == "geheim")
{
    Console.WriteLine("Warm!");
}
else
{
    Console.WriteLine("Koud!");
}

Doet exact hetzelfde, maar leest van boven naar onder als een lijstje gevallen.

Warm! Koud! Programmeren is eigenlijk “warmer, kouder” spelen met de compiler.

De volgorde telt ⚠️

int score = 17;
if (score >= 10)
{
    Console.WriteLine("Geslaagd");
}
else if (score >= 16)
{
    Console.WriteLine("Met onderscheiding!");
}
Geslaagd

17 >= 10 is al true, dus de tweede voorwaarde wordt nooit bekeken. Zet de strengste voorwaarde eerst.

De eerste ware voorwaarde wint. Zoals aan de kassa: wie eerst komt, eerst maalt.

Wat is de output? 🤔

if (temperature > 30)
{
    Console.WriteLine("Tropisch!");
}
else if (temperature > 20)
{
    Console.WriteLine("Lekker weer");
}
else if (temperature > 10)
{
    Console.WriteLine("Jas mee");
}
else
{
    Console.WriteLine("Blijf binnen");
}
temperature Output
22 Lekker weer
35 Tropisch!
10 Blijf binnen

Bij 10 graden binnenblijven. Typisch Belgisch weerbericht.

Handig voor de oefeningen: %

De modulo-operator % geeft de rest van een deling.

Console.WriteLine(10 % 3);  // 1
Console.WriteLine(14 % 5);  // 4
Console.WriteLine(8 % 2);   // 0 → 8 is even
Console.WriteLine(7 % 2);   // 1 → 7 is oneven

Een getal is even als number % 2 == 0.

% is geen korting. Sorry.

Samengevat

Wat Hoe
vergelijken <, >, <=, >=, ==, != → true of false
soms iets doen if (voorwaarde) { ... }
anders iets anders doen if { ... } else { ... }
meerdere gevallen if { ... } else if { ... } else { ... }

Belangrijk

Altijd accolades. En bij else if: de eerste ware voorwaarde wint, dus let op de volgorde.
