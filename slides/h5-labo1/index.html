switch

Het probleem

Een menu met een lange reeks else if’s:

Console.WriteLine("Kies: 1) afbreken  2) opslaan  3) laden");
int option = Convert.ToInt32(Console.ReadLine());

if (option == 1)
{
    Console.WriteLine("Afbreken gekozen");
}
else if (option == 2)
{
    Console.WriteLine("Opslaan gekozen");
}
else if (option == 3)
{
    Console.WriteLine("Laden gekozen");
}
else
{
    Console.WriteLine("Onbekende keuze");
}

Drie keer else if: het programmeursequivalent van “euh… en ook nog…”.

Hetzelfde met switch

switch (option)
{
    case 1:
        Console.WriteLine("Afbreken gekozen");
        break;
    case 2:
        Console.WriteLine("Opslaan gekozen");
        break;
    case 3:
        Console.WriteLine("Laden gekozen");
        break;
    default:
        Console.WriteLine("Onbekende keuze");
        break;
}

switch: geen spelconsole, wel een stuk overzichtelijker.

De regels

  • Elke case eindigt met break. Vergeet je die, dan krijg je fout CS0163.
  • Een case-waarde is een constante (een literal zoals 1 of "ja"), geen variabele. Anders: fout CS9135.
  • De case-waarden hebben hetzelfde type als de waarde die je test.
  • default is optioneel, maar meestal een goed idee.

Vergeet je break, dan weigert C# te compileren. Eindelijk iemand die je verplicht pauze te nemen.

Meerdere waarden, dezelfde code

Zet lege case’s onder elkaar. Dat heet fallthrough:

switch (option)
{
    case 1:
        Console.WriteLine("Afbreken gekozen");
        break;
    case 2:
    case 3:
        Console.WriteLine("Laden of opslaan gekozen");
        break;
    default:
        Console.WriteLine("Onbekende keuze");
        break;
}

Case 2 en case 3 delen hun code. Carpoolen, maar dan voor programmeurs.

Ook met strings

switch (day)
{
    case "zaterdag":
    case "zondag":
        Console.WriteLine("Weekend!");
        break;
    case "woensdag":
        Console.WriteLine("Halverwege!");
        break;
    default:
        Console.WriteLine("Gewoon werken.");
        break;
}
day Output

"woensdag" Halverwege!
"maandag" Gewoon werken.

Weekend detecteren, deel 2. Nu met switch.

Waarom loops?

Terug naar boven

Met if kan je code overslaan. Wat we nog niet konden: terug naar boven gaan om iets opnieuw te doen.

“Voer volgende code uit tot de gebruiker een bepaalde waarde invoert.”

Tip

Zie je dezelfde regels code onder elkaar staan, bijvoorbeeld door copy-paste? Dan kan het bijna zeker korter met een loop.

Tien keer dezelfde regel kopiëren is geen programmeren. Dat is strafwerk.

Soorten loops

  • Definite of counted loop: je weet vooraf hoe vaak. “Toon de getallen van 1 tot 100.”
  • Indefinite of sentinel loop: je weet het vooraf niet. “Voer getallen in, typ 0 om te stoppen.”
  • Oneindige loop: stopt nooit. Soms gewenst, vaak een bug.

In C#: while (0 of meer keer), do while (minstens 1 keer) en for (volgende week).

Een oneindige loop is zoals de discussie over ananas op pizza.

while

Boodschappen doen

Zolang er iets op je lijstje staat… En er staat altijd chocolade op.

In C#

Console.WriteLine("Staat er nog iets op je lijstje? (ja/nee)");
string answer = Console.ReadLine();
while (answer == "ja")
{
    Console.WriteLine("Leg het volgende item in je kar.");
    Console.WriteLine("Staat er nog iets op je lijstje? (ja/nee)");
    answer = Console.ReadLine();
}
Console.WriteLine("Je kan nu naar de kassa.");
  • De voorwaarde wordt vóór elke herhaling gecontroleerd.
  • Is ze meteen false, dan wordt de code nul keer uitgevoerd.
  • Binnen de loop moet iets veranderen, anders stopt hij nooit.

Tellen met while

Wat verschijnt er op het scherm? 🤔

int count = 0;
while (count < 5)
{
    count++;
    Console.WriteLine(count);
}
1
2
3
4
5

Waarom ook 5? Bij count == 4 is 4 < 5 nog true. Binnen de loop wordt het dan eerst 5, en pas daarna getoond.

Tot 5 tellen: het enige wat elke programmeur foutloos kan. Na wat oefening.

Tot de gebruiker stopt

Een sentinel loop: herhalen tot een speciale waarde ingevoerd wordt.

int words = 0;
Console.WriteLine("Typ een woord (stop om te stoppen):");
string input = Console.ReadLine();
while (input != "stop")
{
    words++;
    input = Console.ReadLine();
}
Console.WriteLine($"Je typte {words} woorden.");

Patroon: één keer lezen vóór de loop, en opnieuw lezen als laatste stap in de loop.

“stop” typen om te stoppen. Werkt bij programma’s. Minder bij een kleuter die “waarom?” vraagt.

do while

Een opstel schrijven

Eerst schrijven, dan nalezen. De volgorde die elke leerkracht graag ziet. En zelden krijgt.

In C#

string answer;
do
{
    Console.WriteLine("Typ je opstel:");
    string essay = Console.ReadLine();
    Console.WriteLine($"Je schreef: {essay}");
    Console.WriteLine("Ben je tevreden? (ja/nee)");
    answer = Console.ReadLine();
} while (answer != "ja");
Console.WriteLine("Dan mag je nu indienen.");

Waarschuwing

Achter de while (...) van een do while staat een puntkomma. Vergeet je die, dan krijg je fout CS1002. Bij een gewone while staat er geen.

Die puntkomma vergeet iedereen één keer. Daarna nooit meer. Of twee keer.

while of do while?

int number = 10;
while (number < 5)
{
    Console.WriteLine($"while: {number}");
    number++;
}

number = 10;
do
{
    Console.WriteLine($"do while: {number}");
    number++;
} while (number < 5);
do while: 10

while: 0 of meer keer. do while: minstens 1 keer.

while kijkt voor hij springt. do while springt, en kijkt dan.

Alles samen

Een menu dat terugkomt

string choice;
do
{
    Console.WriteLine("1) Opslaan  2) Laden  3) Stoppen");
    choice = Console.ReadLine();
    switch (choice)
    {
        case "1":
            Console.WriteLine("Opgeslagen.");
            break;
        case "2":
            Console.WriteLine("Geladen.");
            break;
        case "3":
            Console.WriteLine("Tot ziens!");
            break;
        default:
            Console.WriteLine("Onbekende keuze");
            break;
    }
} while (choice != "3");

Het menu in actie

1) Opslaan  2) Laden  3) Stoppen
1
Opgeslagen.
1) Opslaan  2) Laden  3) Stoppen
3
Tot ziens!
  • do while: het menu verschijnt minstens één keer
  • switch: elke keuze krijgt haar eigen case
  • de loop stopt pas als choice gelijk is aan "3"
