Een teller op drie plaatsen: beginwaarde, test en verhoging.

for

Alles op één regel

for (setup; test; update)
{
    // de "body" van de loop
}
  • setup: wordt één keer uitgevoerd, voor de loop start. Meestal maak je hier de loopvariabele aan.
  • test: wordt voor elke ronde gecontroleerd. Is ze false, dan stopt de loop.
  • update: wordt na elke ronde uitgevoerd. Meestal verhoog of verlaag je hier de loopvariabele.

Drie stukken tussen de haakjes, gescheiden door puntkomma’s. Een sandwich van code.

In Flowgorithm

for (int index = 0; index <= 10; index += 2)
{
    Console.WriteLine(index);
}

Next en Done: de enige twee knoppen die je op maandagochtend nodig hebt.

Nieuw: +=

counter += 2;   // betekent: counter = counter + 2;
Kort Lang
counter++ counter = counter + 1
counter-- counter = counter - 1
counter += 2 counter = counter + 2
counter -= 3 counter = counter - 3
counter *= 2 counter = counter * 2

counter += 2: korter typen, langere koffiepauze.

In welke volgorde?

for (int index = 1; index <= 3; index++)
{
    Console.WriteLine(index);
}
Stap index Test index <= 3 Body
setup 1
ronde 1 1 true toont 1
ronde 2 2 true toont 2
ronde 3 3 true toont 3
einde 4 false

Setup, test, body, update. Het klinkt als een fitnessschema, maar dan voor je processor.

for en while: hetzelfde

while

int index = 0;
while (index <= 10)
{
    Console.WriteLine(index);
    index += 2;
}

for

for (int index = 0; index <= 10; index += 2)
{
    Console.WriteLine(index);
}
  • for: als je vooraf weet hoe vaak (een counted loop)
  • while of do while: als je het vooraf niet weet (een sentinel loop)

for met een if

De veelvouden van 7 tot 50:

for (int index = 1; index <= 50; index++)
{
    if (index % 7 == 0)
    {
        Console.Write($"{index} ");
    }
}
7 14 21 28 35 42 49

Veelvouden van 7. James Bond zou trots zijn.

for met een som

De som van 1 tot 100:

int sum = 0;
for (int index = 1; index <= 100; index++)
{
    sum += index;
}
Console.WriteLine(sum);
5050

Gauss had geen for-loop nodig. Gauss wás een for-loop.

Valkuilen

Drie klassiekers

1. De loopvariabele na de loop gebruiken

for (int index = 1; index <= 3; index++)
{
}
Console.WriteLine(index);  // ❌ CS0103

2. Een puntkomma achter de haakjes

for (int index = 1; index <= 3; index++);  // ⚠️ CS0642

3. Eentje te veel of te weinig: < 10 of <= 10? Begint het bij 0 of bij 1?

Er zijn twee moeilijke dingen in programmeren: namen kiezen, cache-invalidatie en off-by-one-fouten.

De Math-klasse

Wiskunde, kant-en-klaar

De klasse Math bevat methoden voor typische wiskundige bewerkingen: machten, wortels, afronden, …

Het volume van een kubus met zijde 4:

double side = 4;
double volumeByHand = side * side * side;  // 64
double volume = Math.Pow(side, 3);         // 64

Math.Pow(grondtal, exponent) is leesbaarder, en makkelijk aan te passen naar een andere macht.

Tip

Typ in Visual Studio Math. en je ziet alles wat de klasse kan. Typ Math.Pow( en je krijgt de uitleg erbij.

De Math-klasse: wiskunde, zonder dat je het zelf moet kunnen. Bijna te mooi.

Machten en wortels

Console.WriteLine(Math.Pow(2, 10));  // 1024
Console.WriteLine(Math.Sqrt(81));    // 9

Waarschuwing

Math.Pow en Math.Sqrt geven een double terug. int power = Math.Pow(2, 3); geeft fout CS0266. Gebruik dus double power = Math.Pow(2, 3);.

Samen met een for:

for (int index = 0; index <= 10; index++)
{
    Console.Write($"{Math.Pow(2, index)} ");
}
1 2 4 8 16 32 64 128 256 512 1024

Math.Pow(2, 10) is 1024. Ongeveer het aantal keer dat je “nog één oefening” zegt.

π

Math.PI is geen methode, maar een vaste waarde: zonder haakjes.

double radius = 5.5;
double circumference = Math.PI * 2 * radius;
Console.WriteLine(circumference);
34,55751918948772

Met Belgische taalinstellingen toont de console een komma. In je code schrijf je altijd een punt: 5.5.

Math.PI: taart voor programmeurs.

Afronden

Console.WriteLine(Math.Round(12.6));         // 13
Console.WriteLine(Math.Round(3.14159, 2));   // 3,14
Console.WriteLine(Math.Floor(12.6));         // 12
Console.WriteLine(Math.Ceiling(12.2));       // 13
  • Math.Round: naar het dichtstbijzijnde getal, eventueel met een aantal cijfers na de komma
  • Math.Floor: altijd naar beneden
  • Math.Ceiling: altijd naar boven

Math.Ceiling: altijd naar boven afronden. Zoals de prijs van een pak friet.
